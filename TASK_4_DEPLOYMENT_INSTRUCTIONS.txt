📞 TROUBLESHOOTING

### "Build Failed on Vercel"
1. Check Vercel Build Logs
2. Look for TypeScript errors
3. Check environment variables
4. Test locally: npm run build
5. Fix locally, commit, push

### "Environment Variable Not Working"
1. Vercel Dashboard → Environment Variables
2. Verify NEXT_PUBLIC_LINKEDIN_URL is set
3. Value is correct: https://linkedin.com/in/...
4. Trigger redeploy (click "Redeploy")

### "Site Shows Old Version"
1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. Check Vercel deployment status
3. If still old, check git push succeeded
4. Wait 1-2 minutes for build

### "Can't Connect GitHub"
1. GitHub Settings → Applications
2. Find Vercel app
3. Revoke access
4. Go back to Vercel, reconnect

### "404 Page Not Found"
This is expected for non-existent routes.
Test: https://your-site.vercel.app/invalid-page
Should show custom 404 page (not default).
